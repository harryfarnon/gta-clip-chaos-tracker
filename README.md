# GTA Clip Chaos live tracker

Public, auto-updating status page for [GTA Clip Chaos](https://www.youtube.com/@GTA6ClipChaos). No footage and no secrets are stored here.

Live site: https://harryfarnon.github.io/gta-clip-chaos-tracker/

The PC autorun writes `live.json` and `index.html` every 5 minutes. A twice-daily job writes `details.json` (views and submission status).
